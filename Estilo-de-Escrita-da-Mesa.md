# ✍️ Estilo de Escrita da Mesa

> [!info] O que é esta nota
> O padrão de escrita do material de campanha (ver [[Índice - Material de Mesa]]).
> **Toda produção nova de material de mesa deve seguir estas regras** — foi
> pedido explícito do mestre ("veja o estilo de escrita para próximas vezes").

## A voz

- **PT-BR falado, direto ao mestre** ("você", "leia", "não explique"). Sem
  formalidade acadêmica; o texto conversa como um co-mestre experiente.
- Frases curtas carregam o impacto. A frase mais importante fica **sozinha
  no parágrafo**, de preferência no fim.
- Números concretos em vez de adjetivos: "trinta e uma cartas", "quatro mil
  metros", "um pisca a cada quatro segundos". Especificidade é o que faz
  parecer verdade.
- O soco emocional vem **depois** de uma banalidade ("...Enfim. Comam
  alguma coisa antes de subir para a rota."). Carinho no fim dá arrepio.

## As regras de ouro do conteúdo

1. **Toda descrição tem três sentidos**: som + cheiro + *uma coisa errada*.
   A coisa errada nunca é gritante — é um detalhe que o jogador percebe
   sozinho (o papel ainda úmido de cola; a luzinha que ainda pisca).
2. **Vilão diz a verdade sobre si mesmo.** O que apavora não é a mentira:
   é perceber que faz sentido. Todo antagonista tem o melhor argumento
   possível na própria boca.
3. **Documento assustador é entediante.** Formulário correto, assinado,
   datado — e a coisa horrível numa palavra do meio, sem sublinhar. Deixe o
   jogador achar.
4. **Plantar e cobrar depois.** Todo texto planta um objeto, nome ou frase
   que volta três sessões depois ("matagal não é floresta"; o nome da noiva
   do casamento). Nunca explicar a planta na hora.
5. **Nada é só cenário**: cena de enchimento sempre tem uma escolha pequena
   com custo. Se não tem, corta.
6. **O horror institucional tem rosto humano**: não é capanga — é atendente
   cansada dizendo "não sou eu, é o sistema", terceirizado com foto das
   filhas, funcionária que fala olhando pra tela.

## A forma (Obsidian)

- Frontmatter YAML com `tags` e `aliases`; `[[wikilinks]]` para tudo que
  tem nota; emojis como marcadores de seção (🗣️ 📖 📄 🎲).
- Callouts com papel fixo:
  - `> [!info] Como usar` — abre TODA nota, explicando o uso na mesa;
  - `> [!quote]` — fala/monólogo/texto lido;
  - `> [!tip] Como falar / Como jogar isto` — direção de atuação;
  - `> [!danger] O que isso planta / SEGREDO DO MESTRE` — consequência e spoiler;
  - `> [!success] Solução (não mostre)` — resposta de cifra/enigma.
- Cada bloco utilizável começa com `` `[ ]` `` para o mestre marcar `[x]`
  quando usar (nada de repetir descrição).
- Monólogo vem com o trio **quando usar / como falar / o que isso planta**.
- Documentos in-world em bloco de código monoespaçado, com burocracia
  realista (números de formulário, carimbos, campos, "c/c").
- Tabelas de uso rápido no fim (d12, "quando abrir cada nota").
- Fechamento padrão: seção `## Ligações` com as notas irmãs.

## Instruções de mesa embutidas

O texto sempre diz **como performar**: onde pausar, quando encerrar a cena
sem deixar responder, quando ficar dez segundos em silêncio, quando NÃO
deixar a mesa consolar um NPC. Direção de cena faz parte do material.
